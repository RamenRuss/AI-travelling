# Данные (мок)

Источник — три Excel-файла. Конвертер кладёт их в `app/data/mock/` как CSV (UTF-8). Руками CSV править можно,
но лучше менять Excel и перезапускать конвертер: он проверяет данные.

## Файлы и колонки

| CSV | Колонки |
|---|---|
| `gas_stations.csv` | `station_name, city, ai92, ai95, ai98, ai100, diesel` (флаги 0/1) |
| `accommodation.csv` | `name, city, type, price_per_night_rub` |
| `transport.csv` | `from, to, departure_point, departure_address, price_rub, transport_type, schedule` |
| `cities.csv` | справочник: `city` (англ. ключ), `city_ru`, `kind` (`city` или `destination`), `lat, lon, aliases` |

Допустимые значения:
- `type` жилья: `hotel`, `hostel`, `guest house`, `recreation base`, `apartment`
- `transport_type`: `bus`, `train`, `commuter train`, `aeroexpress train`, `plane`, `taxi`, `ferry`, `international bus`
- `schedule`: `06:00-21:00` (время работы, точных рейсов нет), `07:00, 16:00` или `08:00` (точные отправления), `24/7`

## Как это работает
Инструменты принимают город по-русски или по-английски, в любом падеже («в Находке»), с опечаткой и псевдонимом
(«Владик»). `cities.csv` — единственное место, где задано соответствие. Конвертер заменяет название города в данных
на английский ключ из `cities.csv`, поэтому в Excel можно писать и «Находка».

`kind=city` — города с координатами (для карты, есть в АЗС/жилье). `kind=destination` — пункты назначения только для
транспорта (Москва, Пусан, аэропорт…), координат нет.

## Добавить новый город
1. Строка в `cities.csv`: `Lazo,Лазо,city,43.4,133.9,`
2. Добавьте строки в Excel и перезапустите `scripts/xlsx_to_csv.py`.
Без шага 1 конвертер откажется записывать файл и покажет, какого города не хватает.

## Особенности и ограничения этих данных (проверено при загрузке)
- В транспорте был 1 полный дубль (поезд Владивосток — Уссурийск): конвертер его убирает автоматически.
- В `schedule` два формата: диапазон («06:00-21:00») — это часы работы, а не рейсы; агент не должен выдумывать точное время.
- Нет дней недели, длительности поездки, адресов жилья, наличия мест, цен на топливо — агент обязан говорить об этом,
  а не придумывать (это прописано в системном промпте `app/agent/llm.py`).
- Многие маршруты есть только в одну сторону (например, Владивосток → Москва без обратного). Инструмент честно
  отвечает «прямых рейсов нет» и предлагает известные направления.
- Чугуевка: единственная АЗС без АИ-95 (`find_fuel` с `fuel_type="95"` вернёт `available_in_city: false`).
- Названия АЗС повторяются в разных городах (`Lukoil #2` есть в 6 городах): это нормально, поиск идёт по городу.
- Координаты городов приблизительные (поле `location.approximate = true`).

## Заменить мок на настоящую БД или API
Оставьте имена функций и формат ответа в `app/tools/mock_data.py` (или напишите новый модуль по `docs/ADD_TOOL.md` с теми
же именами тулов и отключите старый через `DISABLED_TOOLS`). Агент и интерфейс менять не придётся.
